# /form-bin — чтение обычных форм 1С из Form.bin

Обычная форма в выгрузке хранится как контейнер 1С (`Ext/Form.bin`) с двумя потоками:
`form` — описание формы в скобочном формате 1С, `module` — текст модуля формы (BSL).
Скрипт распаковывает контейнер (поддерживает сжатые потоки и вложенные контейнеры),
разбирает скобочный формат и выводит структуру в читаемом виде.

## Как найти форму

```
<Объект>/Forms/<ИмяФормы>.xml            — метаданные формы (FormType = Ordinary)
<Объект>/Forms/<ИмяФормы>/Ext/Form.bin   — сама форма
```

Обычная или управляемая — видно по наличию `Ext/Form.bin` (обычная) или `Ext/Form.xml` (управляемая).
Поиск всех обычных форм объекта: `Glob "**/<Объект>/Forms/*/Ext/Form.bin"`.

## Запуск

```powershell
powershell.exe -NoProfile -File .claude/skills/form-bin/scripts/form-bin.ps1 -Path "<путь>" [-Mode <режим>]
```

`-Path` принимает `Form.bin`, каталог `Ext`, каталог формы или файл `Forms/<Имя>.xml`.

| Режим | Что выводит |
|---|---|
| `overview` (default) | Заголовок, потоки контейнера, дерево элементов (тип, имя, подпись, страницы панелей, кнопки командных панелей → обработчик), обработчики событий, список процедур модуля с диапазонами строк |
| `module` | Текст модуля с номерами строк (`-Offset`, `-Limit`, по умолчанию 400 строк); с `-Name <Процедура>` — только эта процедура |
| `elements` | Только дерево элементов |
| `events` | Только обработчики событий: элемент, тип, код события, процедура |
| `raw` | Поток `form` в скобочном формате с номерами строк — для деталей, которые парсер не выводит (свойства, координаты, привязка к данным) |
| `unpack` | Сохранить потоки в файлы (`module.bsl`, `form.txt`) в `-OutDir` (по умолчанию `%TEMP%\form-bin\...`) и вывести пути — дальше читать через Read |

## Пакетная выгрузка модулей всех обычных форм (кеш для Grep)

Код обычных форм лежит внутри `Form.bin`, поэтому Grep по выгрузке его не видит. Скрипт выгружает модули
всех `Form.bin` в зеркальный кеш с той же раскладкой, что у управляемых форм:

```powershell
powershell.exe -NoProfile -File .claude/skills/form-bin/scripts/form-bin-export.ps1 -ConfigPath configuration [-Force]
```

- Результат: `.formbin-cache\<путь объекта>\Forms\<Форма>\Ext\Form\Module.bsl` (UTF-8 BOM)
- Повторный запуск обновляет только формы, у которых `Form.bin` новее кеша; `-Force` — всё заново. Вся WMS — ~2 с
- Запускать: если кеша нет, после обновления выгрузки (`/1c-batch dump-config`), или когда нужен Grep по формам,
  которых нет в 1c-rag (общие формы `CommonForms`)
- Поиск: `Grep pattern=<текст> path=.formbin-cache glob=*.bsl` → путь подскажет объект и форму,
  дальше `-Mode events` по исходному `Form.bin`, чтобы понять, какая кнопка/событие вызывает процедуру

## Рекомендуемый порядок

1. `overview` — понять состав формы и где какая логика
2. `module -Name <Процедура>` — прочитать нужные обработчики (номера строк из overview)
3. Большой модуль целиком — `unpack` и Read по `module.bsl` (так удобнее листать и искать Grep'ом)
4. Если нужно свойство, которого нет в overview — `raw` и поиск по имени элемента (`{14,"ИмяЭлемента",...}`)

## Как устроен поток `form` (для режима raw)

- Элемент: `{<GUID типа>,<id>,{...свойства...},{...расположение...},{14,"ИмяЭлемента",...},{0}}`
- Подпись: `{1,1,{"ru","Текст"}}`
- Страница панели: `{4,{1,1,{"ru","Заголовок"}},...,"ИмяСтраницы",...}`
- Обработчик события: `{<код события>,e1692cc2-605b-4535-84dd-28440238746c,{3,"ИмяПроцедуры",...}}`
- Кнопка командной панели: `{5,...,<GUID команды>,{8,"ИмяКнопки",...}}`; процедура команды — `{6,<GUID команды>,1,e1692cc2-...,{3,"ИмяПроцедуры"}}`
- События формы: `70000` — ПередОткрытием, `70001` — ПриОткрытии, `2147483647` у полей — ПриИзменении

Справочники (дополняемые, UTF-8):
- `scripts/element-types.txt` — `GUID = ИмяТипа`. Неизвестный тип выводится как `? <GUID>`, а в конце overview —
  список таких GUID: определи тип по имени элемента и допиши
- `scripts/event-codes.txt` — `Тип | код = Событие`. Неизвестное событие выводится как `код N`:
  определи по имени обработчика (обычно `<Элемент><Событие>`) и допиши

## Ограничения

- Принадлежность элементов конкретной странице панели не определяется: выводятся страницы и элементы панели списком
- Привязка полей к данным (ПутьКДанным), координаты и оформление не разбираются — смотри `raw`
- Только чтение. Изменить обычную форму можно только в конфигураторе — в задаче так и указывать
  («добавить страницу в Панель1 формы ФормаОтчета в конфигураторе»)
